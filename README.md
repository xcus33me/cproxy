# cproxy — Claude через ваш сервер

**Откройте приложение → укажите сервер → пользуйтесь Claude.**

cproxy направляет Claude через ваш зарубежный сервер. Обычный браузер, SSH и остальные рабочие приложения продолжают пользоваться своей сетью. После установки прокси работает в фоне: держать терминал открытым не нужно.

## Первый запуск

Скачайте проект через **Code → Download ZIP**, распакуйте и откройте терминал в папке проекта.

**CachyOS / Arch Linux:**

```bash
./cproxy
```

**Windows 10/11 — обычный PowerShell:**

```powershell
.\cproxy.ps1
```

При первом запуске из исходников приложение собирает интерфейс автоматически. Если предложено установить Go или недостающие пакеты, согласитесь. В готовом архиве с бинарником в папке `bin` сборка не нужна; такие архивы собираются в GitHub Actions → **build terminal app**. Если Windows запрещает запуск скрипта, [здесь описано, как его разрешить](docs/windows.md#зависимости-и-политика-скриптов).

### Заполните три поля

| Поле | Что указать |
|---|---|
| **Адрес сервера** | IP или имя вашего зарубежного VPS |
| **Пользователь** | Имя пользователя, с которым подключаетесь к серверу по SSH |
| **SSH-ключ** | Ваш приватный ключ без `.pub`; обычно уже выбран автоматически |

На Linux можно написать `~/.ssh/id_ed25519`. На Windows укажите полный путь к файлу.

**Enter / Tab** — дальше, **Shift+Tab** — назад, **Esc / Ctrl+C** — отмена. Перед установкой появится экран проверки: можно вернуться и исправить любое поле. Если подключение не получилось, данные останутся в мастере для повторной попытки.

Выберите **«Установить / сохранить»** и дождитесь окончания. Всё — дальше откроется главное меню.

Порты и режим ключа определяются по умолчанию. Fingerprint и исходящий IP вводить не требуется. Нестандартные порты доступны в **«Дополнительных настройках»**.

> Нужен ваш сервер с уже настроенным SSH-доступом по ключу. Если такого доступа ещё нет, воспользуйтесь [инструкцией по подготовке SSH](docs/ssh-setup.md). cproxy не создаёт сервер и не устанавливает Firefox или Claude Code.

## Каждый день

Откройте меню из папки проекта той же командой: `./cproxy` на Linux или `.\cproxy.ps1` на Windows.

В меню всего пять пунктов:

- **Открыть Claude в Firefox** — отдельное окно браузера с готовыми настройками. Войдите в Claude и пользуйтесь. Основной Firefox останется обычным.
- **Запустить Claude Code** — запустить установленный Claude Code через сервер.
- **Проверить соединение и IP** — узнать, работает ли подключение.
- **Настройки и управление** — сменить сервер, включить, выключить, перезапустить прокси или посмотреть ошибки.
- **Выйти** — закрыть меню. Фоновый прокси продолжит работать.

Открывайте Claude именно через cproxy. Если Claude Code даст ссылку для входа, вставьте её в окно Firefox, открытое через меню.

**Ключ с паролем?** Приложение распознает его само и выберет защищённый режим. После каждого входа в компьютер откройте **«Настройки и управление → Разблокировать ключ»**. Пароль не сохраняется. Для работы без этого шага нужен отдельный ключ без пароля — [подробнее](docs/ssh-setup.md).

### Можно запускать без папки проекта

После установки на Linux:

```bash
~/.local/bin/cproxy
```

В fish один раз выполните `fish_add_path $HOME/.local/bin` — тогда достаточно команды `cproxy` из любой папки.

После установки на Windows:

```powershell
& "$env:LOCALAPPDATA\SelectiveProxy\cproxy.ps1"
```

Исходники и Go для этого больше не нужны.

## Если что-то не работает

Начните с **«Проверить соединение и IP»**. Для повторного подключения выберите **«Настройки и управление → Перезапустить»**.

Одинаковые обычный IP и IP через прокси **не являются ошибкой**: это возможно, например, при включённой AmneziaVPN. cproxy не меняет настройки Amnezia, но VPN может влиять на доступность вашего сервера. [Помощь с частыми проблемами](docs/troubleshooting.md).

Если прокси или сервер недоступен, запуск Claude сообщит об ошибке. Автоматического переключения на обычное соединение нет.

## Обновить или удалить

Для обновления скачайте новую версию проекта и запустите установщик из его папки. В мастере будут заполнены прежние данные; проверьте их и сохраните:

| Действие | Linux | Windows PowerShell |
|---|---|---|
| Обновить | `./linux/install.sh` | `.\windows\install.ps1` |
| Удалить | `./linux/uninstall.sh` | `.\windows\uninstall.ps1` |

При удалении ваш исходный SSH-ключ и данные отдельного Firefox сохраняются.
