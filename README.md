# cproxy

Claude в отдельном Firefox и Claude Code через ваш SSH-сервер.
Обычный браузер, рабочая сеть и остальные приложения продолжают работать как раньше.

## Запуск

Распакуйте готовый архив для своей ОС и архитектуры. Он содержит `cproxy`
и совместимый `sing-box`: Go, PowerShell, Bash и установка служб не нужны.
Архивы собираются в GitHub Actions → **build ready-to-run archives**.
Firefox и Claude Code должны быть установлены отдельно.

Linux:

```console
./cproxy
```

Windows — откройте терминал в распакованной папке:

```console
.\cproxy.exe
```

В мастере укажите VPS, SSH-пользователя и приватный ключ. Можно ввести
`user@server:2222`; IPv6 — `user@[2001:db8::1]:2222`. Для неизвестного
сервера приложение покажет SSH fingerprint и попросит подтвердить его.
Если сервер уже есть в `known_hosts`, его ключ проверяется автоматически.

Ключ с паролем поддерживается: пароль запрашивается при запуске сессии,
не сохраняется, расшифрованная копия ключа на диске не создаётся.

После подключения выберите **Открыть Claude в Firefox** или
**Запустить Claude Code**. Выход из меню оставляет прокси работающим.
**Остановить прокси** завершает сессию. После перезагрузки откройте cproxy
снова; автозапуска при входе в ОС нет.

## Рабочая сеть

cproxy не меняет системный прокси, DNS, маршруты и firewall. В обычных
приложениях рабочие сайты доступны без дополнительных настроек.

В отдельном Firefox и запущенном через cproxy Claude Code частные IP идут
напрямую. Если рабочий сайт открывается по имени, добавьте корпоративный
суффикс в **Настройки → Дополнительные настройки → Домены рабочей сети**,
например `corp.example`. Одного наличия частного IP в локальном DNS
недостаточно: внешние имена по умолчанию разрешаются через VPS.

Все остальные запросы этих приложений идут через VPS. При потере соединения
они завершаются ошибкой; прямого переключения для внешних сайтов нет.
Команды и MCP-инструменты, игнорирующие proxy environment, имеют собственное
сетевое поведение — cproxy не является системным firewall для их процессов.

## Claude Code и вход

Запуск сохраняет текущую рабочую папку и аргументы:

```console
/path/to/cproxy claude
/path/to/cproxy claude --resume
```

Прокси-переменные устанавливаются только дочернему процессу. Native-клиент
Claude Code поддерживается на обеих ОС; стандартный npm wrapper на Windows
запускается через Node без PowerShell/cmd-интерполяции пользовательских аргументов.

OAuth-ссылку для входа открывайте в выделенном Firefox. Её можно передать
команде `cproxy browser "https://…"`. Автоматический запуск браузера из
Claude Code может открыть обычный профиль ОС, поэтому проверьте окно входа.
Если выделенное окно уже открыто, cproxy покажет ссылку для вставки в него;
он не отправляет её в обычный браузер. После изменения настроек прокси
закройте выделенный Firefox и откройте его снова через cproxy.

В профиле Claude отключены WebRTC, HTTP/3 и DoH. Функции, которым нужен
UDP/WebRTC, включая некоторые звонки, могут быть недоступны.

## Команды

```console
cproxy setup
cproxy start
cproxy stop
cproxy status
cproxy doctor
cproxy browser
cproxy claude [аргументы]
cproxy logs
cproxy run
```

`run` держит прокси в переднем плане до Ctrl+C. `status` проверяет собственный
управляющий процесс; `doctor` проверяет SSH и HTTPS через прокси и показывает IP.
Одинаковые обычный и проксируемый IP сами по себе не являются ошибкой.

Настройки: Linux `$XDG_CONFIG_HOME/cproxy` или `~/.config/cproxy`;
Windows `%APPDATA%\cproxy`. Состояние/журнал: Linux `$XDG_CACHE_HOME/cproxy`
или `~/.cache/cproxy`; Windows `%LOCALAPPDATA%\cproxy`.

При обнаружении старой установки мастер предлагает перенос. Сохраняются
ключ сервера, путь исходного ключа, внутренние исключения и профиль Firefox.
Старый сервис/задача отключается только после проверки принадлежности.
При ошибке перехода восстанавливается прежнее состояние. Старые каталоги
и ключи не удаляются. Для удаления новой версии остановите прокси и удалите
распакованный архив; сохранённые настройки и профиль можно оставить.

## Из исходников

Нужны Go 1.25.8+ и sing-box 1.14.x в PATH или рядом с собранным бинарником.

```console
go build -o .build/cproxy ./cmd/cproxy
go run ./cmd/cproxy
go test ./...
go run ./cmd/bundle -os linux -arch amd64
go run ./cmd/bundle -os windows -arch amd64
```

Сборщик архивов скачивает sing-box 1.14.3, сверяет закреплённый SHA256
и добавляет лицензии. Для офлайн-сборки доступен `-engine-archive FILE`.

[Устройство](docs/architecture.md), [решение проблем](docs/troubleshooting.md).

Приложение обеспечивает сетевой маршрут, но не гарантирует доступность Claude
или отсутствие блокировки аккаунта. РФ отсутствует в
[списке поддерживаемых Anthropic стран](https://www.anthropic.com/supported-countries);
использование VPS не меняет правил сервиса.
