# Если не подключается

Начните с `cproxy doctor` и `cproxy logs`. `status` подтверждает только наличие
собственной сессии, а не доступность интернета или аккаунта Claude.

- **sing-box не найден:** запускайте cproxy из готового архива с соседним
  sing-box. При сборке из исходников установите sing-box 1.14.x или укажите
  его полный путь в дополнительных настройках.
- **SSH недоступен:** проверьте адрес/порт VPS, пользователя и приватный ключ.
  В SSHD должен быть разрешён `AllowTcpForwarding`; некоторые провайдеры и
  сети блокируют SSH. cproxy не маскирует SSH под другой протокол.
- **Ключ сервера изменился:** проверьте переустановку VPS через доверенную
  консоль. Сверьте fingerprint и исправьте сохранённый `host_key` и запись
  `known_hosts` только после проверки. Автоматической замены pin нет.
- **Локальный порт занят:** сначала остановите прежнюю установку либо выберите
  другой порт. Приложение не завершает чужие процессы ради освобождения порта.
- **Рабочее имя не открывается в Claude Firefox/Code:** добавьте конкретный
  внутренний suffix в дополнительных настройках. Обычный браузер использует
  прежнюю сеть без этих исключений.
- **Ошибка IP-проверки:** доступ к `https://api4.ipify.org` через VPS обязателен
  для запуска. Проверка может временно отказать из-за сетевой ошибки сервиса.
- **После обрыва или смены VPN:** попробуйте новый запрос; stream-сессия может
  прерваться. При необходимости выполните `stop`, затем `start`. Существующий
  VPN всё ещё может влиять на маршрут до VPS.
- **Вход открыл не то окно:** вставьте OAuth-ссылку в выделенный Firefox.
  `cproxy browser "https://…"` запускает профиль, если он закрыт; если уже
  открыт, команда показывает ссылку и просит вставить её в существующее окно.
- **Повреждён файл состояния:** закройте/остановите свою сессию, сохраните
  копию runtime `session.json` и удалите только этот файл. Он не содержит
  SSH-ключ или пароль. Не удаляйте каталог Firefox или исходный ключ.

При ключе с паролем после завершения сессии пароль нужен снова. `run`
позволяет наблюдать сессию в переднем плане; Ctrl+C останавливает её.

Разрыв прокси не переключает внешние запросы на обычную сеть. Это не
гарантирует отсутствие блокировки аккаунта: правила Anthropic и доступность
сервиса не управляются этим приложением.
