# Подготовка VPS

Нужен существующий SSH-доступ по файловому ключу Ed25519, RSA или ECDSA.
Проверьте обычное подключение к серверу. В SSHD должен быть разрешён TCP
forwarding; дополнительный серверный sing-box не требуется.

Для отдельного ключа можно использовать стандартную команду OpenSSH:

```console
ssh-keygen -t ed25519 -f ~/.ssh/cproxy_ed25519
```

Добавьте публичную часть ключа в `authorized_keys` нужного пользователя VPS
через доверенную консоль или существующее SSH-подключение. В cproxy указывайте
приватный файл без `.pub`. Для ключа с паролем cproxy запросит пароль при
начале сессии, не меняя исходный файл.

Отпечаток серверного ключа можно сверить в консоли VPS:

```console
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub
```

Если сервер уже известен OpenSSH, используются стандартные `known_hosts`,
включая хешированные записи. Изменённые и отозванные ключи блокируют
подключение. Первый fingerprint требует независимой проверки: простое
подтверждение неизвестного ключа само по себе не доказывает подлинность VPS.
