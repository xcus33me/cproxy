# cproxy implementation plan

**Goal:** explicit per-application HTTP/SOCKS5 proxy, pinned SSH, no system networking changes.
**Spec:** the detailed user brief in this session; docs/architecture.md records the resulting design.
**Execution:** inline in the supplied new repository, as requested. No deployment to this machine or VPS.

## Constraints
- Bash + jq on Linux, PowerShell 5.1+ on Windows; sing-box >= 1.12.
- One shared JSON template, loopback IPv4 only, final ssh, no public direct rule.
- UDP rejected, protected Anthropic domain rule before private-only exceptions.
- Native user service/task, staged check, rollback, ownership markers, no key passphrase saved.
- Unattended dedicated key or manually unlocked session copy of encrypted key.

## Tasks
1. Configuration: tests for JSON escaping, pinned host key, ports, private exclusions, protected rule order; implement shared template and native renderers.
2. Linux: tests with isolated HOME and external-command fixtures for wrappers, exit codes, blocked startup, transactional reinstallation and removal; implement library, installer, unit, CLI, wrappers.
3. Windows: executable PowerShell contract tests for generation, wrapper isolation and rollback; implement native equivalents and hidden task supervisor.
4. Verification: offline suite, syntax, real sing-box check and local SSH forwarding integration where possible; separate opt-in real VPS outage tests.
5. Documentation: Russian README, SSH restrictions, Firefox privacy, Claude child environment, Amnezia diagnostics, Windows and manual acceptance checklist. Review all security and rollback paths.

## Review focus
- Paths with spaces/quotes; avoid shell expansion and Windows argument loss.
- Encrypted key lifecycle and interrupted startup; do not store passphrase.
- Port ownership and accidental deletion of unrelated files/tasks.
- Existing NO_PROXY/lowercase environment and curl configuration bypass.
- Rollback after check/start/network failure, both enabled and stopped states.

## Execution record
- Shared template/native renderers and private-only policy implemented.
- Linux installer/CLI/wrappers/uninstall implemented; disposable HOME transaction regressions run.
- Windows equivalents and SID-specific hidden scheduler supervisor implemented; common tests run on Linux PowerShell 7, native Windows fixture suite prepared for CI only.
- Authoritative documentation checked; real sing-box 1.14.3 check and loopback SSH integration run.
- Independent review findings addressed; no deployment/publishing performed.
- Verification and manual acceptance boundaries recorded in docs/verification.md.

Decisions: work in supplied new checkout (no existing commits/files to isolate); allow other systemd Linux only with preinstalled dependencies; encrypted key uses explicit manual session copy, no stored passphrase; Firefox profile is isolated by path rather than profiles.ini registration. Costs/limits: other Linux is not a supported auto-package path; Windows decrypted session copy requires manual lock and encrypted disk for crash protection; main Firefox/OS routing remain unaffected by cproxy but independent VPN state can change them.
